# Certificate Generation Project

## Project Overview
This project is a web-based Certificate Generation System developed using Python and Flask. It allows users to enter their details and generate certificates.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- GitHub

## Project Structure
- `app.py` – Main Python application.
- `templates/index.html` – Home page for entering user details.
- `templates/certificate.html` – Certificate display template.
- `README.md` – Project documentation.

## Features
- User-friendly interface.
- Enter user details through a web form.
- Generate and display certificates.
- Simple and easy-to-use system.

## How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Run the application using `python app.py`.
4. Open the local URL shown in the terminal.
